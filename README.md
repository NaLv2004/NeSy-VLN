# NeSy-VLN

神经符号视觉导航研究代码。神经网络从观测生成匿名状态定义、离散状态转移和子目标；符号规划器根据生成的转移系统选择动作。

## 代码组织

- `nesy_vla/`、`configs/`：早期 NeSy 模块与配置，也是部分历史实验的依赖。
- `predictive_rules/predictive_nesy/`：生成规则、感知和环境接口。
- `predictive_rules/`：按原目录名保存依赖和历史实验源码。不同实验的具体实现位于对应 Git 分支。
- `scripts/`、`tools/`、`tests/`：训练、部署、诊断及契约检查工具。部署脚本保留当时的路径与设备配置，请阅读后再运行。
- [分支、用途及结果](docs/BRANCHES.md)。每个实验分支另有 `EXPERIMENT.md`。
- [环境及外部资产](docs/RUNTIME.md)。权重、数据集与渲染结果不进入 Git。

## 当前结果及解释

当前已确认的普通场景短中距离开发集最好结果是 v71 第 500 次更新：50/80，即 62.5%；原 v68 基线为 44/80。该开发集短距离和中距离各 40 个任务，chair/table 各 40 个，最多 32 个动作。v72 为 35/80；v73 为 43/80；v75 为 38/80；v76 修复评估循环后为 47/80。不同历史划分的成绩不能直接横向比较。这些是开发集结果，不是独立最终测试结果，也尚未达到超过 80% 的目标。

当前路线区分匿名观测 O（64 个编号）和离散记忆 M（32 个编号）。规则和子目标由网络生成；有限状态递推从所有候选动作推导选择。实际 O 可随观测更新，M 的实际观测校正仅在允许的规则更新边界进行。分支之间存在具体约定差异，以该分支源码和说明为准。早期实现说明另见 `docs/legacy-implementation.md`，不代表当前路线。

## 使用方式

```bash
git clone https://github.com/NaLv2004/NeSy-VLN.git
cd NeSy-VLN
git switch exp/v68-goal-probability
```

本仓库保留研究源码原貌，未打包成可独立安装的产品。运行需准备训练数据、冻结视觉权重、来源检查点、Habitat 环境和共享模拟器代码，并核对训练脚本的设备及路径配置。克隆和切换分支不会启动训练。

## 版本管理约定

公共修改提交到 `main`；实验改动提交到对应分支。提交前检查文件大小和凭证，权重通过外部路径及 SHA-256 标识。禁止将数据、模型、视频、缓存及密码提交到仓库。第三方参考源码未重新打包，使用时从原仓库获取并遵循其许可证。
